# مراجعة تكافؤ مهني مقابل Betaflight Configurator

- **الفرع:** `codex/web-app-foundation`
- **نسخة FPV-ARBCON المراجَعة:** `de65146ca410cbb6366c4abe743e176b1f801c41` (بعد نقاط التفتيش A–C)
- **الغرض:** Betaflight Configurator كمعيار **وظيفي واستخدامي** فقط. لا استنساخ بصري، ولا علامات تجارية، ولا أصول منقولة، ولا نقل أعمى لسلوك لا يناسب هذا المنتج.

## ⚠️ حاجز موثّق: تعذّر تثبيت رقم إصدار مرجعي

المطلوب كان تسجيل **إصدار/وسم/commit محدد** من Betaflight Configurator. **لم يكن ذلك ممكنًا داخل بيئة العمل هذه**، والدليل:

| المحاولة | النتيجة |
| --- | --- |
| `WebFetch` على GitHub API لأحدث إصدار | `HTTP 403 Forbidden` |
| `curl` على `/releases/latest` و`/tags` | `HTTP 403` — «GitHub access to this repository is not enabled for this session» |
| `add_repo betaflight/betaflight-configurator` | رُفض: «cross-tier adds are not supported in v1» — الجلسة مقيدة بمالك واحد (`melyanneahmed-rgb`) |

**لذلك لا يحمل هذا المستند رقم إصدار.** اختلاق رقم كان سيكون تلفيقًا صريحًا، وهو ممنوع في هذه المهمة أصلًا.

**ما يعنيه ذلك لقراءة هذا المستند:**

- **عمود FPV-ARBCON مُتحقَّق من الكود** — كل ادعاء عن منتجنا مربوط بملف وسلوك قابل للفحص في هذا المستودع.
- **عمود Betaflight يصف أنماط سير عمل مستقرة ومعروفة** (بنية التبويبات، سلوك الاتصال، جدول المنافذ، تدفق التفليش) وليس فحصًا حيًّا لبناء بعينه. التفاصيل الدقيقة المرتبطة بالإصدار **قد تكون تغيّرت**.
- **كل صف موسوم بدرجة الثقة**: `STABLE` (نمط راسخ عبر إصدارات طويلة) أو `VERSION-SENSITIVE` (يحتاج إعادة تحقق على بناء محدد).
- **لا يُعتمد أي بند من هذا المستند كمبرر لتغيير منتج قبل إعادة التحقق على بناء Betaflight حقيقي.** ما نُفِّذ فعلًا في نقاط التفتيش A–C استند إلى **تدقيق مستخدم حقيقي على منتجنا** (`docs/WEB_REAL_USER_AUDIT.md`) لا إلى هذه المقارنة.

## ما زال ناقصًا (بصدق، بلا تجميل)

1. **بقية الشاشات لا تستغل سطح المكتب.** Setup وMotors وPorts وGPS وConfigurations أعمدة مفردة. هذه أكبر فجوة متبقية بعد نقطة التفتيش C.
2. **بنية تنقل سطح مكتب.** قائمة جانبية دائمة بدل شريط سفلي هاتفي — تحتاج غلافًا خاصًا بالويب يحترم قيد `MainTabsScreen`.
3. **تفصيل سبب فشل التعريف.** المهلة والبرنامج الثابت القديم والاستجابة المشوّهة كلها تعرض رسالة واحدة؛ الكائن المميِّز مخزَّن ولا تقرأه أي واجهة.
4. **Ports كجدول** بدل بطاقات.
5. **اختصارات لوحة المفاتيح** وتنقل تبويبات بها.
6. **Receiver وPID وBlackbox** — غائبة عمدًا ولن تُضاف لتحسين شكل المصفوفة.

- كشف كل خيار خام دفعة واحدة: بواباتنا الأمنية مقصودة ولن تُخفَّض لمجرد المطابقة.
